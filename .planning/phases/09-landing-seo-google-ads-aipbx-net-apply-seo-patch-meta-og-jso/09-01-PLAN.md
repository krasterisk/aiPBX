<objective>
Establish the build-time constant chain that the entire phase depends on:
`__SITE_URL__`, `__GOOGLE_ADS_ID__`, `__ADS_SIGNUP_LABEL__`. These flow env →
webpack config → buildOptions type → DefinePlugin → `declare const`, mirroring the
existing `__GA4_MEASUREMENT_ID__` chain exactly (D-07). Also register the constants
in Jest globals so Wave 2 unit tests (`usePageMeta.test.ts`, `initAnalytics.test.ts`)
can set/reset them.

`window.location.origin`) and analytics IDs must come from build env, NOT hardcoded
gtag in `index.html` (RESEARCH anti-pattern). Nothing else in the phase compiles
until this chain exists.
Output: Four-file constant chain + `.env.example` doc + Jest globals.
</objective>
