# Phase 10 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope surfaces:** OA dashboard (`OperatorDashboard`), new `SidePanel` drill-down stack, new «Темы» section, tag chips in call journal / call card / export, taxonomy CRUD in project settings.

**Sources:** `10-CONTEXT.md` (D-01…D-30, all LOCKED), `10-RESEARCH.md` (Patterns 1–7, Pitfalls 1–10), `PROJECT.md` (UI rule: `redesign-v3` only), `.cursor/rules/aipbx-core.mdc` (i18n ru+en DoD), and the live token files listed under **Design System**.

### shadcn gate — resolution

`components.json` not found; `tailwind.config.*` not found. The stack is React 18 + Webpack (not Vite/Next). The gate was **resolved to "no" without asking the user**, on locked evidence rather than preference:

1. `PROJECT.md` Agent Rule 3 and `.cursor/rules/` restrict new UI to `shared/ui/redesign-v3/`; shadcn would introduce a fourth parallel UI generation on top of `deprecated/`, `redesigned/`, `mui/`, `redesign-v3/`.
2. The phase brief locks the existing redesign-v3 / CSS-var system and explicitly forbids inventing a new palette.
3. A full token system already exists in `src/app/styles/variables/design-system.scss` (spacing, radius, shadows, status colours, chart palette, chip/badge, z-index) and `variables/global.scss` (type scale).
4. Adding Tailwind + shadcn is a cross-cutting refactor, which violates the one-GAP-per-phase scope rule (C7).

**Registry safety gate is therefore not applicable** (no registry, no third-party blocks). See **Registry Safety**.

## Spacing Scale

Declared values (all multiples of 4). Every value maps to an existing token — **use the token, not the px literal**.

| Token | Value | CSS var | `FlexGap` / `CardPadding` | Usage in this phase |
|-------|-------|---------|---------------------------|---------------------|
| xs | 4px | `--space-1` | `gap='4'` | Icon-to-label gaps, metric label/value pairs |
| sm | 8px | `--space-2` | `gap='8'`, `padding='8'` | Chip rows, compact list items, evidence quote inner gaps |
| — | 12px | `--space-3` | `gap='12'` | KPI stat grid gap (existing `cls.statsGrid`), tag-chip row in journal |
| md | 16px | `--space-4` | `gap='16'`, `padding='16'` | Default element spacing, panel body padding on mobile, topic-card grid gap |
| lg | 24px | `--space-6` | `gap='24'`, `padding='24'` | **Section card padding and top-level section gap** (manager-first density, D-27); panel header + body padding on desktop |
| xl | 32px | `--space-8` | `gap='32'` | Gap between the dashboard's mid-chart block and the «Темы» / «Рейтинг» pair |

| 3xl | 64px | `--space-16` | — | Panel header height; page-bottom breathing room |

**Exceptions:** none. Two non-spacing dimensions are fixed by decision and must not be read as spacing tokens: the side-panel widths (see **Panel Contract**) and the `600px` mobile breakpoint (`@include mobile`).

**Density change required by D-27:** the dashboard root is currently `VStack gap={'16'}`. Raise the **top-level section gap to `'24'`** and keep section-card padding at `'24'`. Nested content inside a card stays at 16/12/8. This is the whole of the "larger sections, less clutter" mandate — do not invent additional density knobs.

## Typography

Exactly 4 sizes, exactly 2 weights. All map to existing `--font-*-redesigned` tokens and to `Text` component props — **use `<Text size=… bold>` rather than raw font CSS**.

| Role | Size | Weight | Line Height | Token / component |
|------|------|--------|-------------|-------------------|
| Label | 12px | 400 | 14px (1.17) | `--font-xs-redesigned` · `<Text size='xs' text=…>` — timestamps, sample-size hints, table column headers, tag chips, "по последним N звонкам" |
| Body | 16px | 400 | 24px (1.5) | `--font-m-redesigned` · `<Text size='m' text=…>` — quotes, rationales, descriptions, call-list rows, empty-state body |
| Heading | 24px | 700 | 32px (1.33) | `--font-l-redesigned` (Roboto) · `<Text size='m' title=… bold>` — section titles («Темы», «Рейтинг операторов»), panel title |
| Display | 32px | 700 | 40px (1.25) | `--font-xl-redesigned` (Roboto) · `<Text size='l' title=… bold>` — the single headline number at the top of the operator panel and the tag panel |

**Weights:** exactly two — regular **400** and bold **700** (`Text` `bold` prop → `font-weight: 700`). The `chip-base` mixin renders the 12px Label role at 700; that is bold emphasis on an existing role, **not** a third weight.

Rules:
- Exactly **one** Display element per panel view (the headline metric). A second big number in the same view is a violation.
- Section titles are Heading; card titles inside a section are Body/bold. Do not escalate a card title to Heading to make it feel important.
- Quotes render at Body with `@include text-clamp(4)` — never shrink quote text below 16px to fit more of it.

## Color

60/30/10 split, expressed in the project's own theme variables. Values shown as `dark / light`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-redesigned)` — `#0c1214 / #eff5f6` | Page background **and** the `SidePanel` paper background (panel reads as a continuation of the app, not a foreign sheet) |
| Secondary (30%) | `var(--glass-bg-primary)` over `var(--light-bg-redesigned)` — `rgba(21,28,31,0.6) / rgba(226,238,241,0.7)` | Section cards, topic cards, panel header bar, evidence rows, metric rows, call-list rows. Applied via `@include glass-card-primary` / `<Card variant='glass' border='partial'>` |
| Accent (10%) | `var(--accent-redesigned)` — `#5ed3f3 / #00c8ff` | See reserved-for list below |
| Destructive | `var(--status-error)` (= `var(--cancel-redesigned)`) — `#d95757 / #f77` | Destructive actions only (taxonomy theme deletion) |

**Accent reserved for** — exactly these six, nothing else:

1. The drill-down affordance on an interactive row/card: the trailing chevron icon, plus the `rgba(94,211,243,0.3)` hover border already supplied by `@include hover-card-row`.
2. Keyboard focus rings — `@include focus-visible` on panel header buttons, operator rows, topic cards, evidence rows, and call rows.
3. The **selected** metric row inside the operator panel: 2px left rule in accent + `var(--icon-bg-secondary)` fill.
4. The single primary button in the «Темы» empty state («Настроить темы проекта») — `var(--button-primary-bg)`, which already resolves to accent in both themes.
5. The active project chip in the chip row (existing behaviour, unchanged).
6. The panel breadcrumb "back" label text.

**Explicitly NOT accent:** tag chips at rest (neutral `var(--chip-bg)` + `var(--chip-border)`), metric values, topic-card numbers, section titles, body text, StatCard icons, table headers, the close (×) button.

**Semantic colours (a separate axis from the 10% accent — reuse, never re-derive):**

| Meaning | Token | Where |
|---------|-------|-------|
| Good / high | `var(--status-success)` | Metric values via the existing `metricVisual` + `MetricPolarity` helpers in `OperatorDashboard.tsx`; positive sentiment |
| Mid | `var(--status-warning)` | Metric values via `metricVisual` |
| Bad / low | `var(--status-error)` | Metric values via `metricVisual`; negative sentiment |
| Neutral | `var(--status-neutral)` | Neutral sentiment; "no data" hints |

Panel metric colours **must** come from the same `metricVisual` / `normalizeRate` helpers the dashboard uses. A panel that colours a score differently from the row the manager clicked destroys the credibility of the whole drill-down (D-02).

**Tag colours:** `TagDefinition.color` is optional in the taxonomy schema. When present, render it **only** as a 8px leading dot inside the chip; the chip background and border stay neutral. This keeps an arbitrary user-chosen colour from competing with the accent budget and from failing contrast on either theme.

**Contrast:** Body and Label text use `var(--text-redesigned)` (`#dbdbdb` on `#0c1214`; `#141c1f` on `#eff5f6`) — both exceed 4.5:1. Never place Body text in `var(--hint-redesigned)` (`#555`) on the dark background; that combination fails AA and is reserved for borders.

### Destructive actions in this phase

| Action | Confirmation approach |

## Panel Contract (D-01, D-02, D-03, D-30)

**Component:** new `src/shared/ui/redesign-v3/SidePanel/` on MUI `Drawer anchor="right"` (RESEARCH Pattern 2). **Never nest a second Drawer** — one instance, driven by the `PanelEntry[]` stack (Pattern 1).

### Dimensions

| Viewport | Width |
|----------|-------|
| `@include mobile` (≤600px) | `100vw` — fullscreen (D-30) |
| 601–1023px | `min(480px, 92vw)` |
| `@include desktop` (≥1024px) | `clamp(480px, 38vw, 560px)` (D-30 range, fully used) |

Height `100%`. `overflow-y: auto` with `@include custom-scrollbar`. Background `var(--bg-redesigned)`, text `var(--text-redesigned)`, `border-left: var(--glass-border-primary)`. **Do not set `z-index` by hand** — keep MUI's modal layer so focus trap, scroll lock, and backdrop stay consistent.

### Header (sticky, 64px)

`@include flex-between`, horizontal padding 24px (16px on mobile), background `var(--glass-bg-primary)`, `border-bottom: 1px solid var(--divider-solid)`.

- Left: back control — rendered **only when the stack depth is > 1**. `ChevronLeft` (20px, `--icon-size-lg`) + the «Назад к {context}» label in accent. 44×44 minimum hit area.
- Centre/left-flow: panel title at Heading, `@include text-truncate`.
- Right: close (×) — icon-only, 44×44, `aria-label` «Закрыть панель», **not** accent-coloured.

Both controls carry `@include focus-visible`.

### Body — the metric → evidence → calls chain (D-02)

| Stack entry | Body |
|-------------|------|
| `operator` | Display headline: the operator's average score. Then the metric list — one row per metric that **has** evidence (D-08 drops the rest entirely; no greyed-out placeholder rows). Each row: metric label (Body), value coloured by `metricVisual` (Body/bold), trailing accent chevron. |
| `operatorMetric` | Display headline: that metric's average. `sampleSize` and the capped-sample notice at Label. Then up to **5** evidence items, each a `glass-card-tertiary` block: quote (Body, `@include text-clamp(4)` + «Показать полностью» when clamped), rationale (Body), call date (Label). Whole block clicks through to the call. |
| `tag` | Display headline: call count. Then the D-16 summary row — avg score, sentiment mix, success rate — as a 3-up stat strip (single column on mobile). Then the paginated call list. |
| `call` | Leaf view: `ReportShowAnalytics` + transcript. Back pops to the metric/tag context that opened it (D-03). |

Body padding 24px desktop / 16px mobile; 16px gap between blocks.

### Interaction rules

- Opening a call **pushes** onto the stack; it never navigates to `/calls` and never touches the `insightDrilldown` `sessionStorage` path (D-03).
- Back pops one level; close clears the whole stack. ESC and backdrop click both map to **close**, not back — MUI's default.
- Panel filters are the dashboard's `startDate` / `endDate` / `projectId` / `userId`, passed as props (D-06). Never re-read Redux inside the panel.
- No URL/query state; the panel is not shareable (D-07).
- Row hover uses `@include hover-card-row`; every clickable row is a real `<button>` or has `role="button"` + `tabIndex={0}` + Enter/Space handling.

## Accessibility Contract

Not optional — the panel is the phase's headline surface and a hand-rolled overlay is the classic failure point (RESEARCH, Don't Hand-Roll).

| Requirement | How |
|-------------|-----|
| Focus trap, ESC, scroll lock, `aria-modal`, focus restoration | Inherited from MUI `Drawer`; do not disable `keepMounted`-adjacent defaults or re-implement key handlers |
| Panel labelling | `PaperProps={{ 'aria-label': title }}`; title also rendered visibly in the header |
| Interactive rows | Real `<button>`, or `role="button"` + `tabIndex={0}` + Enter/Space; never a bare clickable `<div>` |
| Focus visibility | `@include focus-visible` (2px accent outline, 2px offset) on every new interactive element |
| Touch targets | 44×44 minimum for icon-only controls (panel back, close, chip ×) |
| Icon-only controls | Always an `aria-label` from `t()` |
| Motion | Slide transition is MUI's default; `animations.scss` already honours `prefers-reduced-motion` — do not add a custom always-on animation that bypasses it |
| Contrast | Body/Label text on `--text-redesigned` only; `--hint-redesigned` is a border colour, not a text colour |
