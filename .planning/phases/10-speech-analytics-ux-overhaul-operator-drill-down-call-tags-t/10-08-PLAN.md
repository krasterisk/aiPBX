Ship the «Темы» report: a project-gated dashboard section listing each configured theme with its volume and quality (D-15, D-29), placed below the mid-chart block or builder grid and above the operator ranking (D-25, D-26), with both of its empty states distinct and the no-taxonomy one linking into project settings (D-21) — plus the theme drill-down panel that summarises a theme and lists its calls (D-16).

It reuses the panel and stack from 10-06 wholesale, which is exactly what the single-owner stack design was for.
Output: the section with its two empty states and expand control, the theme panel body, and the placement plus gating on the dashboard.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server response → DOM | Theme names and per-theme statistics render as card titles and panel headings |
| user selection → API request | A theme id and the dashboard's filters become query parameters on the call list |
| empty-state action → navigation | The not-configured state routes the user to project settings |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-08-01 | Tampering | theme name rendered in a card title and panel heading | high | mitigate | Names render as React children; no raw-HTML injection is introduced. The full name is exposed through the native hover attribute rather than any markup path. Length and content were capped at the 10-03 write boundary. |
| T-10-08-02 | Information Disclosure | theme call list crossing tenants | high | accept-with-note | Enforcement is server-side: the theme filter is applied inside the list endpoint's tenant scope (T-10-05-04). The client adds no authorisation logic, which is the correct division; this row records that the client is not the control point. |
| T-10-08-03 | Information Disclosure | call metadata retained after the panel closes | medium | mitigate | The call list is fetched under the existing operator-analytics cache tag and the panel stack is component state only, so closing the panel discards which theme and which call were inspected (D-07). |
| T-10-08-04 | Tampering | open-redirect through the empty-state action | low | mitigate | The action targets an in-application route constant, never a value from the response. |
| T-10-08-05 | Denial of Service | very large taxonomy rendering every card | low | mitigate | Server-side entry cap from 10-07 plus the client-side display threshold with an explicit expand control. |
| T-10-08-06 | Information Disclosure | misleading counts leading to wrong coaching decisions | low | mitigate | The header count is the server total and the panel figures come from the same aggregation as the card, so the section, the panel and the list cannot disagree. |
| T-10-08-SC | Tampering | package-manager installs | low | accept | This plan installs nothing; 10-RESEARCH.md § Package Legitimacy Audit records zero new packages for the phase. |
</threat_model>
