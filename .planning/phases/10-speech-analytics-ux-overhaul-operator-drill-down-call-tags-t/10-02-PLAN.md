Build the two reusable pieces the whole drill-down experience rests on: a right-anchored, mobile-fullscreen `SidePanel` in the current UI generation (D-01, D-30), and a typed panel-stack model whose push/pop semantics give D-03's "opening a call stacks inside the same panel, back returns to where you were" without ever mounting a second overlay.

Copy their styling seam, do not mutate either one.
Output: one new `redesign-v3` component with tests, one pure stack model with tests, and a corrected UI-layer rule.
</objective>

## Trust Boundaries

| Boundary | Description |

| user input → application state | Keyboard and pointer events drive stack transitions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-02-01 | Tampering | panel title / children rendering | medium | mitigate | Titles and body text render as React children only; `dangerouslySetInnerHTML` is not introduced anywhere in the shell, so a hostile taxonomy or operator name cannot execute. |
| T-10-02-02 | Information Disclosure | drill-down state persisted outside the component | medium | mitigate | The stack model has no storage, URL or store dependency, so panel contents are never left behind in a shared or persisted location after close (D-07). |
| T-10-02-03 | Denial of Service | overlay traps the user with no exit | low | mitigate | Close is reachable three ways (control, Escape, backdrop) and focus handling comes from the library modal rather than hand-rolled key listeners. |
| T-10-02-04 | Tampering | mutating a caller's stack array in place | low | mitigate | Helpers return new arrays; a spec assertion covers non-mutation. |
| T-10-02-SC | Tampering | package-manager installs | low | accept | This plan installs nothing; every library used is already a direct dependency per 10-RESEARCH.md § Package Legitimacy Audit. |
