# Calls

> A log of all assistant calls: caller, duration, which bot answered. Open recordings and transcripts from here.

## How to open

Left menu → **Calls**.

![Calls log](/docs/screenshots/calls.png)

## Typical workflow

1. Set the date range at the top.
2. Filter by **assistant** or analytics **project** if needed.
3. Click a row for details: audio, transcript, token usage.
4. From the [overview dashboard](./06-dashboards.md), AI Insights can drill down here with filters applied.
